title: Quick start
description: Install createshipyard from npm and scaffold an App Shipyard app. Version 1.1.0.
---

App Shipyard is the kit. The npm package is `createshipyard`.

## What you need

Git, and Node.js 20 or newer. npm ships with Node, so `npx` is already there. The folder name has to be a lowercase npm name: it starts with a letter or digit and then uses only letters, digits, and hyphens. `my-app` is valid. The folder must be missing or empty.

The later Expo toolchain check is stricter than the installer. It accepts Node.js 22.13 or newer on the 22 line, 24.3 or newer on the 24 line, or an even major of 26 or newer.

## Create an app

```bash
npx createshipyard my-app
```

npm downloads `createshipyard` and runs it. The current release is 1.1.0. The command copies the Flutter template, compiles `/ship-*` commands for Claude Code, and writes `AGENTS.md` and `.shipkit/state.json`. It initializes git on branch `main` and makes an initial commit when `user.name` and `user.email` are set. It then runs `npm install` inside `my-app`. Pass `--platform expo` for the publishable app, with the paywall, pricing note, Supabase backend, design shell, English catalog, and legal drafts.

The last lines for the default Flutter template are:

```text
Created my-app

Next steps:
  cd my-app
  This platform template is still a stub. Create the publishable app with --platform expo
```

## Flags

```bash
npx createshipyard my-app --agent cursor --platform expo --pm npm
```

- `--agent` is `claude`, `cursor`, `opencode`, or `all`. The default is `claude`. `all` writes Claude Code, Cursor, and OpenCode.
- `--platform` is `expo`, `flutter`, `android`, or `ios`. The default is `flutter`. `ios` is refused when the machine is not macOS.
- `--pm` is `npm`, `pnpm`, or `yarn`. The default is `npm`. That choice is the installer for the new app.
- `--no-install` skips dependency installation. The new folder still gets the template, the commands, and git.

`npx createshipyard --help` prints the same usage line.

## Next command

```bash
cd my-app
```

Open that folder in the agent you selected and run `/ship-start`. Cursor users who passed `--agent cursor` see: open this folder in Cursor and run `/ship-start`.

The Flutter template is the one this package copies by default. Pass `--platform expo` for the Expo template. The Flutter, Android, and iOS templates are stubs. They are not buildable projects yet.
