## Build the CLI

From a checkout of this repository:

```bash
pnpm install
pnpm cli:build
node cli/dist/index.js my-app
```

That copies the Expo template, compiles slash commands, writes `AGENTS.md` and `.shipkit/state.json`, initializes git, and installs dependencies. Pass `--no-install` to skip the install.

`npm run pack:npm` writes `release/createshipyard-1.0.0.tgz`. That file is the npm package. It is not on the registry until it is published. After that publish, `npx createshipyard my-app` is the same scaffold.

## Flags

- `--agent` is `claude`, `cursor`, `opencode`, or `all`. The default is `claude`. `all` writes Claude Code, Cursor, and OpenCode.
- `--platform` is `expo`, `flutter`, `android`, or `ios`. The default is `expo`. `ios` is refused when the machine is not macOS.
- `--pm` is `npm`, `pnpm`, or `yarn`.
- `--no-install` skips dependency installation.

## Next command

Open the new folder in the agent you selected and run `/ship-start`.

## What is implemented

The Expo template is the one the scaffold copies by default. The Flutter, Android, and iOS templates are stubs. They are not buildable projects yet. Antigravity and Codex are written by `scripts/compile-commands.mjs`, not by `--agent all`.
