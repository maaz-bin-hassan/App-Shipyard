# 1.1.0

Apply this guide when `.shipkit/state.json` `kitVersion` is below `1.1.0` and the latest release is at least `1.1.0`.

## Changes

- `scripts/android-sdk-platform.mjs`: keep `chooseApiLevel`. It returns the requested level when that platform is installed, otherwise the newest higher installed level, otherwise the newest installed level. It returns `null` only when no platform is installed. The command prints `android-sdk-<level>` and exits 0 for that level. It prints `missing` and exits 1 only when `chooseApiLevel` returns `null`.
- `.claude/commands/ship-env-check.md`, `.cursor/commands/ship-env-check.md`, `.opencode/commands/ship-env-check.md`, and `.agents/skills/ship-env-check/SKILL.md`, when the file exists: the Android SDK platform check passes when the script prints `android-sdk-` plus any installed API level. Do not require the `expected` token. CocoaPods passes at `1.17.0` or newer, and its expected text is `.`.

## Leave untouched

Do not edit `src/screens/`, Dart under `lib/`, Kotlin under `app/src/`, or Swift sources. Those files belong to the developer unless a guide names one path. Do not change the selected `platform`.

## Check

`chooseApiLevel([36], 37)` equals `36`. `chooseApiLevel([], 37)` equals `null`. Each named `ship-env-check` file is either missing or says an installed API level passes. `git diff` shows no other path.

## Rollback

`ship-update` records the pre-update commit on branch `ship-update-checkpoint-*` and in `.shipkit/update-checkpoint.json`. Rollback runs `git reset --hard` on that `head`, deletes only untracked files this guide created, and runs `git stash pop` when `stashed` is true.
