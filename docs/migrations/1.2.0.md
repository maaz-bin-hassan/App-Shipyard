# 1.2.0

Apply this guide when `.shipkit/state.json` `kitVersion` is below `1.2.0` and the latest release is at least `1.2.0`.

## Changes

- No application files. `createshipyard --platform expo` from kit `1.2.0` writes the paywall, pricing note, Supabase backend, design shell, English catalog, and legal drafts into a new app. An app created before `1.2.0` keeps the source it already has. The default platform remains Flutter.

## Leave untouched

Do not edit `src/screens/`, Dart under `lib/`, Kotlin under `app/src/`, or Swift sources. Those files belong to the developer unless a guide names one path. Do not change the selected `platform`. Do not replace an existing Expo app with the new scaffold.

## Check

`git diff` shows no path from this guide. `docs/migrations/1.2.0.md` is present in the kit docs copied beside the app.

## Rollback

`ship-update` records the pre-update commit on branch `ship-update-checkpoint-*` and in `.shipkit/update-checkpoint.json`. Rollback runs `git reset --hard` on that `head`, deletes only untracked files this guide created, and runs `git stash pop` when `stashed` is true.
